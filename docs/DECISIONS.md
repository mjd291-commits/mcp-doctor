# MCP Doctor — Decision Log

## D001 — Separate project
MCP Doctor is a standalone product and codebase. MotorSelectIQ may later be used as a test environment but is not a dependency.

## D002 — TypeScript first
The first implementation uses TypeScript/Node because the official MCP TypeScript SDK directly supports client transports and is a good fit for a CLI plus later web application.

## D003 — Read-only by default
Alpha discovery does not invoke arbitrary tools. Safety and predictable behavior are more important than broad active testing.

## D004 — Deterministic before generative
Compatibility findings should be generated by explicit rules first. LLM explanations may later summarize evidence but should not be the source of truth for pass/fail results.

## D005 — Scanner before proxy
A compatibility proxy is likely the strongest commercial layer, but we must first accumulate reliable failure signatures and repair rules through scanning/testing.
